# Security

CapCut Collect is beta software that reads project files and extracts collection archives. Use current releases and keep source projects available until destination playback is verified.

If you discover a security issue, use GitHub private vulnerability reporting when it is enabled for the repository. If unavailable, open an issue requesting a private contact method without posting exploit details, sensitive files, or personal paths.

Never attach credentials, full project archives, private media, or unredacted diagnostics to a public issue. Prefer a small synthetic reproduction. Native integration is experimental and restricted to a validated CapCut/Qt combination.
